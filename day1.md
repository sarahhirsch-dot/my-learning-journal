# Tag 1

## Was habe ich gelernt?
Ich habe heute mein erstes eigenes Repository für dieses Lerntagebuch angelegt, `my-learning-journal`,
direkt auf GitHub. Danach habe ich gelernt, was "Klonen" bedeutet: Ein Repository, das bis dahin nur
online bei GitHub existierte, wird dabei komplett auf meinen eigenen Rechner heruntergeladen –
inklusive der kompletten Historie. Dabei wird auch automatisch die Verbindung zu GitHub eingerichtet,
sodass ich später einfach pushen kann, ohne das manuell einzustellen.

## Welches Problem hatte ich?
Nach dem Klonen habe ich den heruntergeladenen Ordner auf meinem Rechner zuerst nicht wiedergefunden,
weil ich beim Auswählen des Speicherorts nicht aufgepasst hatte. Ich dachte außerdem kurz, ich müsste
das Repository erst "pullen", bevor ich damit arbeiten kann – dabei hatte ich es ja noch gar nicht
lokal vorliegen.

## Wie habe ich es gelöst?
Beim erneuten Klonen habe ich bewusst meinen Desktop als Speicherort ausgewählt, damit ich den Ordner
garantiert wiederfinde. Außerdem habe ich verstanden, dass "Pull" nur zum Aktualisieren einer bereits
vorhandenen lokalen Kopie dient – für ein komplett neues Repository ist "Clone" der richtige erste
Schritt, nicht "Pull".
